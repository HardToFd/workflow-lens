# 技能: 安全基线自审
- 挂载点: S4
- 触发条件: 总是
- 作用: S4 自审环节的最低安全检查线(通用,按目标项目技术栈补充"侧重"小节)
---

## 通用

- [ ] diff 中无硬编码密钥/token/内网地址(配置一律走 env/config)
- [ ] 新增外部输入(HTTP 参数、队列消息体、文件上传)都有校验,不信任上游
- [ ] SQL/命令一律参数化,拼接用户输入进查询或 shell = 直接 ✗
- [ ] 新接口有鉴权;数据查询经过既有的数据权限层,不绕过
- [ ] 日志不打印敏感数据(证件号、手机号、token、密钥)
- [ ] 文件路径/下载地址不可由用户输入直接拼接
- [ ] 外部服务调用有超时与**有界重试**;失败后的阻断/降级/补偿策略符合业务语义且可观测——关键依赖(鉴权、支付、持久化)失败通常必须停止当前操作,非关键依赖才可降级不阻塞
